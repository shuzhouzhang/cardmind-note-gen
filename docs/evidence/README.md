# Agent Reliability evidence

The files in this directory are generated by `scripts/agent-eval/cli.ts` and deliberately exclude prompts, note bodies, diffs, provider response bodies, credentials, authorization headers, cookies, and token-shaped strings.

- `agent-eval-v1.json` / `.md`: deterministic offline Replay result. “Scenario pass” and “guardrail assertion pass” describe scripted Runtime behavior; they are not model-routing accuracy.
- `agent-live-smoke-v1.json` / `.md`: optional single-run NoteGen endpoint compatibility snapshot. Absence of this file is not converted into a success rate.

Exit codes are 0 (gate passed), 1 (comparable result below threshold), 2 (configuration/provider not comparable), and 130 (user interruption). All tool effects are synthetic and in memory. The v1 evidence does not establish production security, cross-run idempotency, multi-Agent support, Responses API support, or production MCP capability.
